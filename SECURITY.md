# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take system security seriously. If you discover a security vulnerability within the Student Performance Prediction AI platform, please report it via private email to `security@studentai.io`.

Please include:
- A clear description of the vulnerability
- Reproduction steps or proof-of-concept payload
- Potential impact assessment

We aim to acknowledge receipt within 48 hours and provide a resolution timeline.
